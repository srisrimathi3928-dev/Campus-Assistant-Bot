# AI-Powered Student Assistance Chatbot

## Project Overview

The AI-Powered Student Assistance Chatbot is a web-based application designed to help college students quickly access important academic and campus-related information through a simple chatbot interface.

## Features

* **Attendance** – Provides information about attendance requirements.
* **Fees** – Gives guidance about semester fee payment.
* **Exam Information** – Provides examination-related information and notices.
* **Library** – Shares library timings, borrowing and renewal information.
* **Faculty** – Helps students find faculty and academic guidance information.
* **Placement** – Provides placement updates and career-related information.

## Technologies Used

* HTML
* CSS
* Python
* Flask
* AI Chatbot

## Purpose

The main purpose of this project is to provide students with quick and easy access to commonly required college information in one place.
